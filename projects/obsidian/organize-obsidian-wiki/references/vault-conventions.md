# Vault Conventions

Use the current `skunklabs-uk/obsidian` workspace instructions to locate the
source vault. Treat it as read-only unless the user authorizes a specific write.

## Language

- Write notes and responses in Italian unless the source note or user request uses another language.
- Use "vault" for the real Obsidian directory.
- Use "workspace" for the current clone of `skunklabs-uk/obsidian`.
- Use "wiki personale" for curated notes intended as durable conversational memory.
- Use "nota grezza" for unprocessed capture.
- Use "nota curata" for reviewed wiki material.

## Workspace Structure and Templates

Use the current workspace's `Governance/Vault-Structure.md` and
`Governance/Document-Placement-Guide.md` for directories, metadata and templates.
Do not copy directory names or frontmatter from an older workspace.

## Review Checklist

- Every curated note has a clear title.
- Important concepts link to related notes.
- Dates are absolute, not relative.
- Open questions are explicit.
- Raw source notes remain available when a summary is created.
